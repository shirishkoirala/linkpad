# Linkpad release graphics

Promotional artwork and screenshot panels for the initial release.

## Direction

- Deep forest green, pale lime and warm ivory.
- Reuse the approved linked phone, monitor and cursor identity.
- Copy: “Your computer. At your fingertips.”
- Feature line: “Touchpad · Keyboard · Remote”.
- No real pairing codes, personal information or unverified platform claims.

## Deliverables

- Store listing copy: [Android](store-listing-android.md) and [iOS](store-listing-ios.md), including platform-specific fields and asset upload references.
- `google-play-feature.png`: Google Play feature graphic; target 1024 × 500.
- `social-preview.png`: GitHub/social preview; target 1280 × 640.
- `google-play-icon.png`: existing approved artwork exported at 512 × 512.
- `app-store-icon.png`: existing iOS artwork at 1024 × 1024.
- `app-store-header-3840x1646.png`: wide App Store header, using the approved branding and actual rendered Touchpad/Remote UI. Editable source: `app-store-header.html`; regenerated by `export_store_panels.cjs`.
- `app-store-search-1920x1280.png`: matching Search Results asset, laid out at the slot's supported 1920 × 1280 dimensions. Uses the search variant of the header HTML and the same exporter.
- `*-master.png`: original generated marketing artwork before upload-size export.

Generated with the built-in Imagegen tool. Verify actual pixel dimensions and inspect the final store previews before uploading. These graphics do not change the installed app icons.

## Prompt direction

Create minimal editorial marketing artwork using the approved Linkpad logo as the identity reference. Forest green background, pale lime symbol, warm ivory typography, generous negative space, and crisp readable text. Place Linkpad branding and the headline “Your computer. At your fingertips.” on the left, with a large linked phone/monitor/cursor illustration on the right. Include “Touchpad · Keyboard · Remote”. Avoid app screenshots, store badges, QR codes and extra claims. Use generous margins and deliver flat artwork without a presentation frame.

## Store screenshot panels

`store-screenshots/android/` contains four 1080 × 1920 promotional panels. `store-screenshots/iOS/` contains four 1290 × 2796 panels. Each folder also includes `overview.png` for review; the overview is not an individual store upload.

For the App Store Connect “iPhone with Dynamic Island (medium display)” slot, use `store-screenshots/iOS-medium/`: four 1206 × 2622 panels. These are laid out for that canvas rather than stretched from the larger exports.

For the required 13-inch iPad slot, use `store-screenshots/iPad-13/`: four 2064 × 2752 panels based on actual iPad-sized Flutter layouts. Raw iPad UI captures are under `screenshots/iPad/`. Do not upload the overview image.

The panels cover Touchpad, Remote, Keyboard and Settings. They use actual Flutter widget renders with production fonts and a sample connected computer named “Living room”. They are rendered fixtures, not physical-device captures: no real connection or latency measurement is implied. No app screen is AI-generated. The surrounding artwork and captions are editable in `store-panels.html`.

Raw UI renders are retained under `screenshots/`. The screenshot tool uses the existing test peer and does not add a demo mode to the shipped app. Confirm the device-size slot accepted by App Store Connect before uploading the iOS exports. Review native-device rendering as part of final release testing.

To regenerate:

1. From `mobile/`, run `flutter test tool/store_screenshots_test.dart --concurrency=1`. On macOS this loads installed San Francisco fonts for iOS; Android uses Flutter's bundled Roboto fonts.
2. From the repository root, run `node mobile/tool/export_store_panels.cjs` with Playwright available through `NODE_PATH`. Set `CHROME_PATH` if Chrome is not at the default macOS path.

The generator checks each screen for Flutter rendering exceptions. Panel exports wait for fonts and all source images to load. Design review corrected caption overlap, missing default image sources and tinted shadows; no design rules were suppressed.
